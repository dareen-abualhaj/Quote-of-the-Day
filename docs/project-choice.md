## Why this one (3–5 sentences)

We chose the Quote of the Day project because it provides a practical, clean, and highly extensible use case for multi-tool AI integrations. It allows us to split core responsibilities cleanly across team members, covering daily quotes, keyword searches, and category discovery. By leveraging structured schemas and offline JSON fallbacks, we can ensure smooth, reliable live demos without worrying about external API rate limits or downtime. Additionally, it offers a solid foundation for adding personalized features like favorites in future iterations.
